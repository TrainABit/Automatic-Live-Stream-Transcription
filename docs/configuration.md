# Configuration reference

Every setting is read from the environment (or a `.env` file) with the prefix `LST_`.
Precedence, highest first: command line flags, process environment, `.env`, defaults.
An invalid value is a startup error that names the variable, never its value.

This file is generated by `scripts/gen_config_docs.py` from `config.py`.

## Capture

| Variable | Default | Description |
|---|---|---|
| `LST_CAPTURE_SAMPLE_RATE` | `16000` | Mono PCM sample rate handed to the STT providers. |
| `LST_CAPTURE_LIVE_CHUNK_SECONDS` | `2.5` | Chunk length for live sources: short, to keep end-to-end latency low. |
| `LST_CAPTURE_FILE_CHUNK_SECONDS` | `5.0` | Chunk length for files and recordings: longer, since latency is irrelevant. |
| `LST_CAPTURE_QUEUE_SIZE` | `32` | Live capture queue depth; when full the oldest chunk is dropped. |
| `LST_CAPTURE_FILE_QUEUE_SIZE` | `8` | File capture queue depth; the producer waits instead of dropping. |
| `LST_CAPTURE_RECONNECT_INITIAL_DELAY` | `1.0` | First reconnect delay in seconds; grows with full jitter. |
| `LST_CAPTURE_RECONNECT_MAX_DELAY` | `30.0` | Upper bound of the reconnect delay in seconds. |
| `LST_CAPTURE_MAX_RECONNECT_ATTEMPTS` | `0` | Consecutive reconnect attempts before giving up; 0 means never give up. |
| `LST_CAPTURE_RESOLVE_CACHE_SECONDS` | `20.0` | How long a resolved media URL is reused. |
| `LST_CAPTURE_AUDIO_STALL_SECONDS` | `30.0` | Restart the capture when no audio arrives for this long; 0 disables. |
| `LST_CAPTURE_STALE_PLAYLIST_STALLS` | `2` | Audio stalls on a frozen HLS playlist before reselecting. |
| `LST_CAPTURE_STREAM_FORMAT` | `bestaudio/best` | yt-dlp format selector for resolved sources. |
| `LST_CAPTURE_FFMPEG_BINARY` | `ffmpeg` | ffmpeg executable to use. |
| `LST_CAPTURE_FFMPEG_LOGLEVEL` | `warning` | ffmpeg's own log level. |
| `LST_CAPTURE_COOKIES_FILE` | `unset` | Netscape cookie file passed to yt-dlp (age-gated or bot-checked sources). |
| `LST_CAPTURE_PROXY` | *(secret)* | Proxy URL for yt-dlp; may embed credentials, hence a secret. |
| `LST_CAPTURE_HLS_WINDOW` | `false` | Opt in to reading HLS playlists ourselves for a controlled live window. |
| `LST_CAPTURE_HLS_LIVE_START_INDEX` | `-3` | Segment to start from, relative to the live edge, when the window is used. |

## Speech to text

| Variable | Default | Description |
|---|---|---|
| `LST_STT_PROVIDER` | `local` | Speech-to-text provider: local, onnx, openai, openrouter, mock or none. |
| `LST_STT_MODEL` | `unset` | Model name; `None` selects the provider default (see `DEFAULT_STT_MODELS`). |
| `LST_STT_LANGUAGE` | `unset` | ISO language code, or `None` to auto-detect. |
| `LST_STT_FALLBACK` | `none` | Provider used when the primary keeps failing (typically `local`). |
| `LST_STT_DEVICE` | `cpu` | Device for local inference (cpu or cuda). |
| `LST_STT_COMPUTE_TYPE` | `int8` | Quantisation of the local model (int8, float16, ...). |
| `LST_STT_THREADS` | `4` | CPU threads used by local inference; raise it on a multi-core machine. |
| `LST_STT_NICE` | `0` | Niceness applied to local inference threads; 0 leaves priority alone. |
| `LST_STT_WORD_TIMESTAMPS` | `false` | Ask the provider for word-level timestamps where it supports them. |
| `LST_STT_VAD_FILTER` | `true` | Let the local model skip non-speech with its voice activity filter. |
| `LST_STT_MODELS_DIR` | `~/.cache/livestream-transcriber/models` | Where downloaded ONNX models live (see `lst models fetch`). |
| `LST_STT_CACHE_DIR` | `unset` | Cache transcripts of identical audio here, so replays and benchmarks of the same recording do not pay for the same chunk twice. Off when unset. |
| `LST_STT_WORKERS` | `1` | Concurrent transcription requests. |
| `LST_STT_QUEUE_SIZE` | `8` | Chunks buffered in RAM ahead of the STT workers. |
| `LST_STT_SPILL_CHUNKS` | `240` | Chunks that may spill to disk beyond the RAM queue; 0 disables spilling. |
| `LST_STT_BUDGET_USD` | `unset` | Stop using a cloud provider once its estimated spend reaches this; `None` is unlimited. |
| `LST_STT_TIMEOUT_SECONDS` | `60.0` | Per-request timeout of a provider call. |
| `LST_STT_BREAKER_FAILURES` | `3` | Consecutive failures that open a provider's circuit breaker. |
| `LST_STT_BREAKER_COOLDOWN_SECONDS` | `30.0` | How long an open breaker waits before trying one request. |
| `LST_STT_MAX_LAG_SECONDS` | `45.0` | Overload guard: pause STT when it falls this far behind; 0 disables. |
| `LST_STT_MAX_DROP_RATIO` | `0.25` | Overload guard: pause STT when this share of chunks was dropped. |
| `LST_STT_OVERLOAD_WINDOW_SECONDS` | `120.0` | Sliding window the overload guard looks at. |
| `LST_STT_RECOVERY_PROBE_SECONDS` | `60.0` | Interval of recovery probes while STT is paused. |
| `LST_STT_OUTAGE_SECONDS` | `300.0` | Consecutive failure time after which an STT outage is reported. |
| `LST_STT_HEALTH_LAG_SECONDS` | `30.0` | Lag above which the heartbeat reports the run as degraded. |
| `LST_STT_HEALTH_DROP_RATIO` | `0.05` | Drop ratio above which the heartbeat reports the run as degraded. |

## Speech to text: cloud providers

| Variable | Default | Description |
|---|---|---|
| `LST_OPENAI_API_KEY` / `OPENAI_API_KEY` | *(secret)* | OpenAI (or compatible) API key. OPENAI_API_KEY is accepted too. |
| `LST_OPENAI_BASE_URL` / `OPENAI_BASE_URL` | `https://api.openai.com/v1` | Point this at any OpenAI-compatible transcription server. |
| `LST_OPENROUTER_API_KEY` / `OPENROUTER_API_KEY` | *(secret)* | OpenRouter API key. OPENROUTER_API_KEY is accepted too. |
| `LST_OPENROUTER_BASE_URL` | `https://openrouter.ai/api/v1` | Base URL of the OpenRouter API. |

## Resuming after a stream ends

| Variable | Default | Description |
|---|---|---|
| `LST_RESUME_AUTO` | `true` | Keep probing after a stream ends or is offline, and resume when it returns. |
| `LST_RESUME_PROBE_INTERVAL_SECONDS` | `30.0` | Interval between liveness probes while waiting. |
| `LST_RESUME_BACKOFF_MAX_SECONDS` | `900.0` | Upper bound of the probe interval when probes are inconclusive. |
| `LST_RESUME_ONLINE_STABLE_SECONDS` | `15.0` | How long a source must stay up before it counts as live again. |
| `LST_RESUME_END_SETTLE_SECONDS` | `30.0` | Grace period after the media ends, to drain in-flight audio and transcripts. |
| `LST_RESUME_UNCERTAIN_HOLD_SECONDS` | `90.0` | How long to hold when the source state is ambiguous before deciding. |

## Notifications

| Variable | Default | Description |
|---|---|---|
| `LST_NOTIFY_WEBHOOK_URL` | *(secret)* | Webhook URL. Many webhook URLs embed a token, hence a secret. |
| `LST_NOTIFY_WEBHOOK_FORMAT` | `json` | Payload shape: json, slack or discord. |
| `LST_NOTIFY_WEBHOOK_TOKEN` | *(secret)* | Optional bearer token sent as `Authorization` with webhook requests. |
| `LST_NOTIFY_TELEGRAM_TOKEN` | *(secret)* | Telegram bot token; needs the chat id as well. |
| `LST_NOTIFY_TELEGRAM_CHAT_ID` | `unset` | Chat that receives Telegram alerts. |
| `LST_NOTIFY_TIMEOUT_SECONDS` | `10.0` | Timeout of one notification request. |

## Paths and process

| Variable | Default | Description |
|---|---|---|
| `LST_OUT_DIR` | `out` | Directory for transcript files (jsonl, srt, vtt) and the default database. |
| `LST_RECORDINGS_DIR` | `recordings` | Where lst record stores recordings. |
| `LST_DB_PATH` | `unset` | SQLite database; `None` means `<out_dir>/lst.db`. |
| `LST_HEARTBEAT_SECONDS` | `60.0` | Interval of the periodic health line; 0 disables it. |
| `LST_MEMORY_LIMIT_MB` | `0.0` | Soft RSS limit that triggers back-pressure warnings; 0 disables. |
| `LST_LOG_LEVEL` | `INFO` | DEBUG, INFO, WARNING or ERROR. |
